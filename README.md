# HardKAS

Developer toolkit for building, testing, simulating and debugging Kaspa applications.

HardKAS is designed for Kaspa-native developer workflows:

- transaction building
- UTXO management
- transaction simulation
- wallet-connected signing
- local testing
- localnet/devnet
- traces and replay
- future SilverScripts, vProgs and L2/Igra workflows

## Status

This is an early v0 scaffold.
